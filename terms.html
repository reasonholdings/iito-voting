利用規約

iito members 推しモデル投票　／　制定日：2026年11月1日

本利用規約（以下「本規約」といいます。）は、株式会社リーズン（以下「当社」といいます。）が提供する「iito members 推しモデル投票」（以下「本サービス」といいます。）の利用条件を定めるものです。本サービスをご利用になる方は、本規約の全文をお読みいただき、本規約に同意のうえご利用ください。

第1条（適用及び定義）

  1. 本規約は、本サービスの利用に関する当社と会員との間の一切の関係に適用されます。
  2. 会員は、本規約に同意のうえ本サービスを利用するものとし、本サービスにログインした時点で、本規約に同意したものとみなします。
  3. 本規約において使用する用語の定義は、次の各号に定めるとおりとします。
    1. 「本ファンクラブ」とは、ファンクラブ「iito members」をいいます。
    2. 「プラン」とは、本ファンクラブの有料会員プラン（サポーター、パートナー及びプロデューサー）をいいます。
    3. 「会員」とは、プランに加入し、本サービスを利用する者をいいます。
    4. 「票」とは、本サービスにおける投票に用いるために、当社が会員に付与するものをいいます。
    5. 「投票イベント」とは、当社が本サービスにおいて実施する投票の企画をいいます。
    6. 「モデル」とは、投票イベントにおいて投票の対象となる者をいいます。
    7. 「個別規定」とは、投票期間、集計及び発表の時刻その他の事項について、当社が本サービス上又はお知らせにより定める個別の規定をいいます。
  4. 個別規定は、本規約の一部を構成するものとします。本規約と個別規定の内容が異なる場合は、個別規定が優先して適用されるものとします。
  5. 本ファンクラブの会員資格、会費並びにプランの加入、変更及び解約については、本ファンクラブの会員規約その他の定めによるものとし、本規約は、本サービスの利用についてのみ定めるものとします。

第2条（利用資格及びログイン情報の管理）

  1. 本サービスは、会員に限り利用することができます。未成年の会員は、親権者その他の法定代理人の同意を得たうえで、本サービスを利用するものとします。
  2. 会員は、本ファンクラブに登録したメールアドレス及び会員自らが設定したパスコード（以下併せて「ログイン情報」といいます。）を用いて、本サービスにログインするものとします。
  3. 会員は、自己の責任においてログイン情報を管理するものとし、これを第三者に開示し、又は利用させてはなりません。
  4. ログイン情報を用いて行われた投票その他の行為は、当社の故意又は過失による場合を除き、当該会員本人が行ったものとみなします。
  5. 会員は、ログイン情報が第三者に知られたこと、又はそのおそれがあることを知った場合、直ちにパスコードを再設定し、当社に通知するものとします。

第3条（票の付与）

  1. 当社は、会員に対し、プランに応じて次のとおり票を付与します。
    プラン付与する票の数
    サポーター12票
    パートナー40票
    プロデューサー150票
  2. 当社は、次の各号のいずれかに係る決済が確定したときに、当該決済の対象となるプランに応じた票を付与します。
    1. プランへの新規加入
    2. プランの更新（継続）
    3. プランの変更（上位のプラン及び下位のプランへの変更を含みます。）
  3. 前項の規定にかかわらず、同一の月において、当該月に既に票を付与したプランに係る決済が再度確定した場合、当社は、当該プランの票を重ねて付与しません。
  4. 当社は、会員情報（プランの加入、変更及び解約に関する情報をいいます。以下同じ。）を、投票イベントの期間外においては毎週月曜日に、投票イベントの期間中においては毎日正午に、本サービスへ反映します。反映までの間は、反映前の会員情報に基づき持ち票の表示及び投票の受付を行い、反映した時点で本条の規定に従い票を付与します。
  5. 票は、プランの特典として付与するものであり、当社は、票自体を販売するものではありません。
  6. 投票券の販売その他本条に定める以外の方法により票を取得できる場合の取扱いは、当該販売ページ又は当社のお知らせにおいて定めるところによります。

第4条（票の有効期限、使用順序及び消滅）

  1. 票の有効期限は、当該票が付与された月の翌々月の末日までとします。有効期限を経過した票は、消滅します。
  2. 会員が投票に票を使用する場合、付与された時期の古い票から順に使用されるものとします（前々月に付与された票、前月に付与された票、当月に付与された票の順とします。）。
  3. 会員がすべてのプランを解約した場合、当該会員が保有する票は、その時点ですべて消滅します。
  4. 票は金銭的価値を有するものではありません。会員は、票を現金その他の財産と交換し、又は票の払戻しを受けることはできず、票を第三者に譲渡し、貸与し、売買し、又は相続させることはできません。当社は、消滅した票について、一切の補償を行いません。

第5条（投票、集計及び結果）

  1. 会員は、当社が定める投票期間中に、本サービス上の所定の方法により投票するものとします。
  2. 会員は、送信した投票を取り消し、又は投票先を変更することはできません。ただし、システムの不具合その他の事由により当社が必要と認めた場合は、この限りではありません。
  3. 集計の方法、集計及び発表の時刻並びに結果の利用方法は、投票イベントごとに、本サービス上又はお知らせにより案内します。
  4. 集計結果は、本規約及び個別規定に従い、当社が確定します。
  5. 当社は、本サービスの投票画面において、投票イベントごとに、一のモデルに10票以上を投じた会員に対し、当該モデルに投票した会員のうち得票数上位5名のニックネーム及び票数を表示します（以下「応援ランキング」といいます。）。会員は、自己のニックネーム及び票数が応援ランキングとして他の会員に表示される場合があることに同意のうえ、投票するものとします。

第6条（表示、付与及び集計の誤りの訂正）

  1. 当社は、システムの不具合その他の事由により、持ち票の表示、票の付与又は集計に誤りがあることが判明した場合、本規約の定めに従った正しい内容に訂正します。この訂正により、会員の保有する票が減少する場合があります。
  2. 当社は、前項の訂正を行った場合、影響を受ける会員に対し、本サービス上その他の方法により、その内容を通知します。
  3. 第1項の誤りにより、既に終了した投票イベントにおいて本来保有する票を超えて投票が行われていた場合の集計の取扱いは、会員間の公平に配慮して当社が定め、通知します。
  4. 当社は、第1項の訂正を理由として、会員に対し金銭の支払いを求めることはありません。

第7条（禁止事項）

  1. 会員は、本サービスの利用にあたり、次の各号に該当する行為をしてはなりません。
    1. 他人のログイン情報を使用し、又は自己のログイン情報を他人に使用させる行為
    2. システムの不具合を利用して、本来保有する票を超えて投票し、又は投票しようとする行為
    3. プログラムその他の手段を用いて自動的に投票若しくはアクセスし、又は本サービスに過度な負荷をかける行為
    4. 票若しくはログイン情報を売買し、又は金銭その他の利益の対価として投票を依頼し、若しくは引き受ける行為
    5. 本サービスを不正に解析し、又は改ざんしようとする行為
    6. モデル、他の会員、当社その他の第三者の権利を侵害し、又はその名誉若しくは信用を毀損する行為
    7. 法令又は公序良俗に違反する行為
    8. その他前各号に準ずる行為であって、本サービスの公正な運営を妨げるもの
  2. 会員は、本サービスの不具合を発見した場合、速やかに当社に報告するものとします。

第8条（利用停止等）

  1. 当社は、会員が前条の規定に違反した場合又は違反するおそれが高いと判断した場合、必要な範囲で、ログインの停止、当該違反に係る票の無効化、集計からの除外その他の措置を講じることができます。この場合、当社は、緊急を要するときを除き、事前に当該会員に通知し、弁明の機会を設けるよう努めます。
  2. 前項の措置は、本ファンクラブの会員資格及び会費の取扱いに影響を及ぼすものではありません。これらの取扱いは、本ファンクラブの会員規約その他の定めによります。

  1. 当社は、本サービスの内容を変更し、又は本サービスの提供を終了することがあります。会員に重大な影響を及ぼす変更又は終了を行う場合、当社は、相当の期間をおいて、事前に本サービス上又はお知らせにより告知します。
  2. 当社は、設備の保守点検、システムの不具合、通信障害、天災地変その他やむを得ない事由がある場合、事前の告知なく、本サービスの全部又は一部の提供を一時的に中断することがあります。投票期間中に中断した場合の取扱い（投票期間の延長を含みます。）は、当社が定めて通知します。

第10条（当社の責任）

  1. 当社は、本サービスが中断なく提供されること及び本サービスに誤りがないことを保証するものではありません。ただし、誤りが判明した場合は、第6条の定めに従い訂正します。
  2. 当社は、本サービスに関して会員に生じた損害について、当社に故意又は重大な過失がある場合は、当該損害を賠償します。
  3. 当社の軽過失（重大な過失を除く過失をいいます。）により会員に損害が生じた場合、当社が賠償する損害の範囲は、現実に生じた直接かつ通常の損害に限られるものとします。

  1. 会員は、現在及び将来にわたり、暴力団、暴力団員、暴力団員でなくなった時から5年を経過しない者、暴力団準構成員、暴力団関係企業その他これらに準ずる者（以下「反社会的勢力」といいます。）に該当しないこと、及び反社会的勢力と関係を有しないことを表明し、保証します。
  2. 当社は、会員が前項の表明又は保証に違反したことが判明した場合、何らの催告を要することなく、直ちに当該会員による本サービスの利用を停止することができます。

当社は、本サービスにおける個人情報を、当社が別途定めるプライバシーポリシーに従い、適切に取り扱います。

第13条（権利義務の譲渡禁止）

会員は、当社の事前の承諾なく、本規約に基づく契約上の地位又は本規約に基づく権利若しくは義務を、第三者に譲渡し、貸与し、又は担保に供することはできません。

第14条（本規約の変更）

  1. 当社は、次の各号のいずれかに該当する場合、民法第548条の4の規定に基づき、会員の個別の同意を得ることなく、本規約を変更することができます。

第16条（準拠法及び管轄裁判所）
