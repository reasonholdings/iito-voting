# パスコードログインの公開手順（運営向け）

作成日: 2026-10-27（JST）

確認コードのメールを `info@reason.holdings` から送るための準備と、GAS（スプレッドシートの裏側のプログラム）の入れ替え手順です。
**手順1〜3が終わってから、投票画面（index.html）を公開します。** 先に投票画面だけ公開すると、新しくログインする人が入れなくなります。

---

## 手順0：GASを動かしているGoogleアカウントを確かめる

1. スプレッドシート「iito 投票集計」を開く
2. 上のメニュー「拡張機能」→「Apps Script」
3. 開いた画面の右上に出ているアカウントが「GASを動かしているアカウント」です
   - 手順1は、このアカウントのGmailで行います

## 手順1：Gmailに info@reason.holdings を「送信用のアドレス」として登録する

パソコンのブラウザで行ってください（スマホのGmailアプリではできません）。

1. 手順0のアカウントでGmailを開く
2. 右上の歯車 →「すべての設定を表示」
3. 「アカウントとインポート」タブ →「名前：」の欄の「他のメールアドレスを追加」
4. 出てきた小さな画面で
   - 名前：`iito members`
   - メールアドレス：`info@reason.holdings`
   - 「エイリアスとして扱います」はそのままでかまいません
   - 「次のステップ」
5. 送信サーバーの設定（ロリポップ）
   - SMTPサーバー：`smtp.lolipop.jp`
   - ポート：`465`
   - ユーザー名：`info@reason.holdings`
   - パスワード：ロリポップで設定した info@reason.holdings のメールパスワード
   - 「SSL を使用したセキュリティで保護された接続」を選ぶ
   - 「アカウントを追加」
   - ※ 数字が違うとエラーになります。ロリポップの管理画面「メール」→「メール設定」に書かれている送信サーバーの情報で確かめてください
6. info@reason.holdings 宛に確認メールが届くので、ロリポップのWebメールなどで開き、書かれているリンクを押す（または確認コードを入力する）

## 手順2：GASのプログラムを入れ替える

1. 手順0の「Apps Script」の画面を開く
2. **念のため今のコードを控える**：左の「ファイル」の＋ →「スクリプト」→ 名前を `backup_20261027` にして、今のコードを全部コピーして貼り付け、保存
3. 元のファイル（いつも使っているコード）を開き、中身を全部消す
4. GitHub の `gas/iito_gas_api.gs`（新しい版）の中身を全部コピーして貼り付け、保存（Ctrl+S / ⌘+S）
5. 上の関数の選択欄で `testSetup` を選び「実行」
   - 「承認が必要です」と出たら「権限を確認」→ アカウントを選ぶ →「許可」（メール送信の許可が新しく求められます）
   - 下の「実行ログ」に `★ すべてOK` と出れば成功
   - `✗ 差出人 info@reason.holdings が…登録されていません` と出たら、手順1をやり直してください
6. 右上「デプロイ」→「デプロイを管理」→ 鉛筆マーク（編集）→「バージョン」を「新バージョン」→「デプロイ」
   - URL は変わりません。投票画面の設定を変える必要はありません

## 手順3：Claudeに「デプロイした」と伝える

投票画面（index.html）の新しい版を公開します。公開後、運営のメールアドレスで「はじめての方・暗証番号を忘れた方」から試してください。

## 会員への案内文（例）

> 投票画面のログイン方法が新しくなりました（パスコード方式）。
> 【はじめての方】ログイン画面で「はじめて」を選び、登録しているメールアドレスを入れて「確認コードを受け取る」を押してください。届いた6桁の確認コードと、ご自分で決めたパスコード（4〜6桁の数字）を入力すると、そのままログインできます（最初の1回だけ）。
> 【2回目から】「2回目から」を選び、メールアドレスとパスコードでログインしてください。
> 【すでにログインしている方】投票画面に出る「パスコードを作ってください」から、今のうちにパスコードを作っておいてください。
> 確認コードは info@reason.holdings から届きます。届かない場合は、迷惑メールフォルダや、携帯会社のメールの受信設定（reason.holdings からのメールを受け取る設定）をご確認ください。

## 仕組みのメモ

- パスコードそのものは保存しません。スプレッドシートの「暗証番号」シート（初回に自動でできます）には、元に戻せない形（ハッシュ）だけを保存します
- パスコードを5回続けて間違えると15分ロック。確認コードは10分有効・5回間違えると無効・同じアドレスへは1時間に3通まで
- メールは1日100通まで（GASを動かすアカウントが通常のGmailの場合）。送るのは「はじめて」と「忘れたとき」だけです
- 既にログインしている人（以前のメールリンクでログインした端末）は、そのまま使えます
- 画面での呼び名は「パスコード」（2026-10-27 に「暗証番号／PIN」から変更）。スプレッドシートのシート名とプログラム内の名前（pin）はそのまま
- 確認コードのメール本文の「パスコードを作ってください」は、GASを次に入れ替えたときに反映されます（それまでは「暗証番号を設定してください」のまま）
